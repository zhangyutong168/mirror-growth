# Mirror · 爆款对标与账号增长台

> 输入方向关键词 → 找出最值得模仿的爆款（不只是最火的）→ 分析为什么火 → 告诉你下周拍什么。
>
> 第一个案例赛道：**竞赛升学**（小红书）。

Mirror 是一个内容创作者的增长工作台，回答三个问题：

| 模块 | 问题 | 回答方式 |
| --- | --- | --- |
| 🎯 对标台 `/match` | 该模仿谁？ | 五维榜单（赞/藏/评/效率/收藏率）× 匹配度引擎 —— **最火 ≠ 最适合模仿**，匹配度 = 表现强度 40% × 可复制性 60% |
| 💡 选题洞察 `/insight` | 下周拍什么、标题怎么起？ | 钩子效能榜 + 方向需求×供给象限 + 按优先级排好的选题清单（含起标题建议） |
| 📡 热点雷达 `/radar` | 现在谁在爆？要不要跟？ | 热点 = 超过**作者自己基线**的异常（不是绝对数据高），叠加窗口期判断（可跟/换角度/过窗） |

## 核心洞察（来自真实数据）

- **最火 ≠ 最适合模仿**：点赞榜 Top3 全是百万级外部大号（匹配度 59-70），而收藏率榜全是可复制的图文干货（可复制性最高 93）——匹配度引擎用数据把这两类分开。
- **干货赛道的互动结构**：149 条中 50 条收藏 ≥ 点赞；「干货承诺」钩子藏/赞比 0.92，收藏转化最强。
- **热点的相对性**：一个 200 赞的号发出 2000 赞，比百万号的十万赞更像热点——雷达用作者基线倍数而非绝对值检测。

## 数据说明（诚实声明）

- 内容池 `data/samples/jingsai-shengxue-pool.csv`：**149 条真实笔记**（8 个搜索关键词 × 20 条，134 位独立作者），字段含赞/藏/评/分享/发布时间/作者 ID，从小红书网页版登录态采集。
- 热点雷达当前为**单批快照降级模式**：多数作者在池内只有 1 条，基线用赛道 p90 兜底；「最新」排序二批采集 + T+2 重采（增速信号）在路线图中。
- 所有分析构建期预计算，页面静态输出，**数据不出设备**。

## 技术栈

Next.js 16 (App Router, Turbopack) · React 19 · TypeScript · Tailwind 4 · papaparse

```
lib/
  types.ts     # Note / RankedNote / MatchBreakdown
  pool.ts      # CSV 解析 + 互动结构 + 分位rank
  match.ts     # 匹配度引擎（表现强度 40% × 可复制性 60%）
  hooks.ts     # 标题钩子 7 类规则库 + 互动结构点评
  insight.ts   # 钩子效能 / 需求×供给 / 选题清单
  radar.ts     # 热点检测（作者基线 + 赛道兜底 + 窗口期）
app/
  match/       # 对标台（服务端预计算五维榜单）
  insight/     # 选题洞察
  radar/       # 热点雷达
scripts/
  make-seed-csv.mjs  # 原始采集 JSON → 清洗后 CSV（可复现）
```

## 本地运行
